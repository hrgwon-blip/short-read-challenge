> 공모 부문 2: AI 바이브 코딩 앱 제작 부문

## 📱 앱 실행 방법 (초간단 1초 실행)

1. `index.html` 파일을 **더블 클릭**하면 크롬, 엣지, 웨일 등 브라우저에서 즉시 실행됩니다.
   - 별도의 `node.js` 설치나 서버 구동이 필요 없는 독립 실행형(Self-contained) 웹앱입니다.
2. 스마트폰에서도 확인하고 싶다면:
   - 본 `index.html` 파일을 GitHub Pages 또는 Vercel에 드래그 앤 드롭으로 올리면 즉시 모바일 웹 주소(`https://...`)가 생성됩니다.

## 🌟 핵심 기능 및 심사위원 시연 시연 포인트

1. **스마트폰 모바일 목업 뷰**:
   - 상단의 `📱 모바일 뷰` / `🖥️ 넓은 화면` 버튼으로 화면 크기를 자유롭게 전환할 수 있습니다. (영상 촬영 및 캡처에 매우 용이)
2. **30초 정독 카운트다운 타이머**:
   - 숏폼 보듯 글을 스크롤만 하고 넘기지 못하도록, **30초 동안 집중해서 읽어야 하단의 '3단계 문해력 퀴즈' 버튼이 보라색으로 활성화**됩니다.
3. **AI 3단계 문해력 퀴즈 (어휘력 $\rightarrow$ 핵심 요지 $\rightarrow$ 비판적 추론)**:
   - 고1 수준에 맞춘 3지선다/4지선다 인터랙티브 문제 풀이.
4. **1:1 AI 국어 선생님 오답 과외 힌트**:
   - 오답을 클릭하면 단순 정답만 알려주지 않고, *"본문 몇 번째 문장을 다시 읽어보세요"*라는 친절한 힌트 카드가 뜹니다.
5. **도파민 게이미피케이션 (폭죽 효과 & 연속 출석 스트릭)**:
   - 3문제를 모두 통과하면 화려한 **폭죽 애니메이션(Canvas-confetti)**이 터지고, **'🔥 4일째 성공!'**으로 연속 달성 배지가 누적됩니다 (브라우저 자동 저장).
6. **Gemini Flash AI 실시간 지문 생성**:
   - 상단의 `✨ AI 생성` 버튼을 누르고 주제(예: '우주 탐사', '생성형 AI와 저작권')를 입력하면 Gemini 1.5 Flash API가 새로운 지문과 퀴즈를 실시간으로 만들어냅니다.
   - *API 키가 없어도 기본 내장된 3개 지문(탄소세, 자율주행 윤리, 팝콘 브레인)으로 완벽하게 시연 가능합니다.*

* **01:45 ~ 02:00 (마무리 및 소감)**:
